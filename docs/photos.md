# 写真の読み取り

許可した家族グループへ写真を送ると、メンションなしで解析して返信する。スタンプ・動画・他グループ・個別トークは対象外。

- レシート・領収書・請求書・家計明細：店名、日付、品目、税、合計、支払方法など、見える情報を整理する。読めない数字は推測せず要確認とする。家計簿へは登録しない。
- その他の文字が写った画像：文字起こし。読めない箇所は判読不明とし、長文では一部を省略した旨を表示する。カード・口座・会員番号などは転記しない。
- 文字のない写真：写真に合わせて短く、かわいい感想を返す。人物の名前や関係性は推測しない。

LINEに直接送ったJPEG・PNG・WebP画像、1枚8MBまで。複数枚は1枚ずつ独立して処理する。モデルの読み取りは誤ることがあるため、家計入力に使う場合は元画像で金額を確認する。

LINE Content APIから取得し、既存の予算管理AI Gateway経由でGeminiに渡す。追加のOCRサービス・ストレージ・Secretは不要。早い回答はReply、時間がかかった場合は既存のPushへの切替を使う。

画像のバイナリは処理中のメモリだけで扱い、会話履歴・長期記憶・D1へ保存しない。解析結果も会話履歴へ追加しないため、後日の質問で内容を参照する機能はない。画像IDと処理依頼IDはDOに最大24時間、直近100枚分保持する。LINE上の画像・返信は別途残る。送信取消を受信した画像は未処理の解析・結果送信を中止するが、既にAIへ送ったデータや送信済み返信を取り消すものではない。

外部プロバイダーの画像は処理しない。画像取得期限切れ・サイズ超過・未対応形式・AI利用上限ではその旨を返信する。DB migrationは不要。
