# ADR-0009: 利用範囲を家族グループだけに限定する

## Status

Accepted (2026-10-04)

## Context

家族グループへの制限だけで十分であり、所有者のユーザーIDは不要。
ADR-0006の所有者制限と初回設定手順を変更する。

## Decision

- `LINE_ALLOWED_USER_ID`を廃止し、送信者のuser IDをアプリの入力に持たない。
- `LINE_ALLOWED_GROUP_ID`に一致するグループのbot宛てメンションだけに返信する。
- 1対1、別グループ、roomでは返信しない。
- グループID未設定時は返信しない。署名検証済みのグループからの`@bot グループID`に限り、形式を検証したgroup IDを`group_setup_required`としてログに出す。
- 管理者がログからIDを確認してSecretへ設定する。最初に届いたグループの自動登録はしない。
- 設定後は取得用ログも停止する。不正な形式の設定や認証情報不足はWebhookを503にする。

## Consequences

所有者IDの取得が不要になる。家族は全員同じ利用権限を持つ。
初回設定中は取得コマンドの送信元グループIDがWorkers Logsに保存される。
本文、ユーザーID、認証情報はログに出さない。通常の署名検証とping/pongの仕様は維持する。

## Enforcement

許可グループ、他グループ、1対1、メンション、未設定時の無返信、署名検証前の取得ログ禁止、設定後の取得ログ停止をテストする。
