# 担当者別タスク

「毎月27日18時に、AとBがそれぞれ銀行振込するタスクを作って」のようにbotへメンションして依頼する。名前は確定済み家族プロフィールから対応づける。誰か不明な場合や時刻がない場合は聞き返す。

- 初回の27日18時に家族グループへ通知。その後も未完了の人だけを毎日同じ時刻に通知する。既存5分Cronなので通常0〜5分程度遅れる。
- Aが完了してもBのタスクは残る。各自が自分の完了ボタンを押すか、botにメンション・引用返信で「振込終わった」と伝える。
- 翌月は二人分の新しいタスクを作る。前月の未完了は消えずに残る。複数月残っているときは「10月分を完了」のように指定する。ボタンは表示した期限の分だけを完了にする。
- 「タスク一覧」「振込タスクを停止して」「再開して」「削除して」もメンションして依頼できる。停止中の未完了は保持する。削除は定義と完了・未完了分を消す。
- 日次・週次・月次・年次と間隔指定に対応。時刻は日本時間。31日など存在しない日はその月の末日に寄せる。
- 個別トークへの通知、代理で他人を完了、担当者・周期の直接編集は未対応。編集が必要な場合は停止して新しく作る。

既存リマインダーは完了管理を持たず、これまでどおり送信する。タスクは別のD1データで、会話履歴・記憶を削除しても残る。

初回配備前にmigration `0009_family_tasks.sql` を適用する。未適用の場合はタスクの依頼に準備中と返し、他の会話は継続する。タスクは20件・担当者は各6人まで。未完了を含む実行分が各1000件に達すると新規周期の生成を保留するので、不要な定義は整理する。

ローカルでは模擬送信で検証する。本番LINEでの担当者解決・通知時刻・完了操作の確認は配備後に行う。
