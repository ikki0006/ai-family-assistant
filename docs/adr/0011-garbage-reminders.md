# ADR-0011: 収集設定をD1に保存して定期通知する

## Status

Accepted (2026-10-04)

## Context

収集日前日23時と当日8時に通知する。実際の地域・収集パターンをGitに残さず、設定はSecretではなくDBに平文で保存する。

## Decision

- D1に有効期間、曜日・第何週、日付ごとの置き換え設定を保存する。町名・丁目を保存しない。
- TerraformでCronを管理する。UTC 14時と23時の0、5、10分に起動する。
- LINEのPushを使用し、本文生成にLLMを使わない。
- 日付・朝晩・許可グループから安定したretry keyを作り、成功後にD1へ記録する。
- 5分・10分後の呼び出しは未送信の場合のみ送る。記録にはグループIDの原文を残さない。
- 12月31日〜1月3日は例外未登録なら確認案内に留め、期限切れ設定では通知しない。

## Consequences

収集設定は年度ごとに更新する。年末年始の特別収集日は公式発表後に登録する。
LINEのPush通数を消費する。8時通知は収集直前の最終確認になる。
実データの登録SQL・設定ファイルはGitに入れず、テストには架空データを使う。

## Enforcement

日付境界、第何週、例外・有効期限、再送とLINE retry key、実D1の送信済み判定をテストする。
`pnpm verify`とTerraform validate/planで検査する。
