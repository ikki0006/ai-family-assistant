## 更新方針

現在の仕様は機能別文書、判断の履歴はADR、特定時点の結果は`releases/`に置く。
過去のADRや配備結果を現状に書き換えず、後続へのリンクを付ける。
閾値や料金設定は実装ファイルへの参照を添え、READMEや残タスクへ重複記載しない。
コード上の実装、配備成功、実機で確認した結果を区別する。
