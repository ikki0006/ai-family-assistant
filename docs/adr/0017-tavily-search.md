# ADR-0017: 通常会話で必要な場合だけTavily検索を使う

## Status

Accepted (2026-10-04)

## Context

ユーザーはCloudflare Creditsの追加購入を避け、取得済みTavilyキーの利用を選択した。

## Decision

- 既存の会話Durable Objectの通常回答に検索を追加する。通知解釈、要約、定期送信は検索しない。
- Geminiが最新の発言から検索語または不要をJSONで返す。検索語に私的情報を含めないよう指示するが、完全な匿名化を保証するものではない。
- applicationのWebSearch portをTavily adapterで実装。Basic固定、最大5件、タイムアウト10秒、再試行なし。
- 1回答1検索。1家族のDO SQLiteでUTC暦月900回までを送信前に原子的に予約する。失敗も数え、削除・履歴リセットでは検索使用量をリセットしない。別アプリやキーの他用途の使用量は含まない。
- 検索結果は信頼できない参考資料とし、通知操作には渡さない。検索本文・クエリはログ・記憶に保存しない。最終回答には検索日と実際の参考URLを添付し、通常の7日履歴に保存する。要約では検索した話題だけを残すよう指示する。
- Tavilyキーは.dev.vars / Worker Secret TAVILY_API_KEY。未設定なら従来の会話を維持する。
- 既存TextGenerator契約を維持し、初版はfunction callingではなく検索判定と回答の2段階推論とする。推論はすべて既存Gatewayを通す。

## Consequences

検索有効時は通常回答でも判断用の推論が1回増える。検索費用はGateway予算とは別。生の検索結果は保存しないが、最終回答は従来の履歴に残る。
旧式のメモリなし応答経路は検索非対応。日本語検索の品質は実運用で確認する。

## Enforcement

検索不要・上限・失敗・出典・Basic固定・エラー秘匿をテストし、pnpm verifyを実行する。
