# ADR-0023: 質問と改善承認のクイックリプライ

## Status

Accepted (2026-10-05)

## Context

短い確認の返事にもメンションが必要で、改善承認では内部IDと版の入力を求めていた。

## Decision

- 通常回答と通知の確認質問は、LLMが必要に応じて最大4個・各20文字以内の選択肢を提案する。質問内容を補う回答として処理し、不明な日時・行動を勝手に確定しない。
- LINE postbackのランダムトークンを、既存DOのSQLiteに保存した質問・選択内容へ対応させる。署名検証とグループ制限を通し、メンションなしで応答する。通常質問は質問した話者のみ、15分間有効。
- 改善依頼は改修内容を表示して「承認してPR作成」「キャンセル」を付ける。家族メンバーが選択でき、24時間有効。依頼IDと版は内部で照合し、既存の原子的claim後にだけActionsを起動する。ADR-0021のID入力による承認案内を置き換える。
- 一つ選ぶと同じ質問の全選択肢を無効にする。履歴削除時もボタンの保存内容を消す。Pushへ切り替えた場合も選択肢を保持する。

## Consequences

追加インフラ・D1 migrationは不要。LINE側でボタンが消えた場合や期限切れの場合は再度話しかける。通常の自由文返信は従来のメンション・引用返信ルールを使う。検索付き回答は本文・出典を優先し、選択肢は付けない。

[LINE公式仕様](https://developers.line.biz/en/docs/messaging-api/using-quick-reply/)に従いpostbackを使用する。displayTextはmessageイベントにならないため、専用の受信経路を設ける。

## Enforcement

トークンの話者制限・失効・一度限りの消費、メンションなしの回答キュー投入、Webhook解析、改善の原子的承認をテストする。pnpm verifyで検証する。
