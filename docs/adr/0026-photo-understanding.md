# ADR-0026: 家族写真の自動読み取り

## Status

Accepted (2026-10-08)

## Context

写真内の文字や家計情報を読み取り、文字のない写真にはかわいい感想を返したい。当初のメンション限定から、ユーザーの指示により許可家族グループの全画像を対象とする方式へ変更した。

## Decision

- LINEの署名検証と既存のグループ制限を通った画像イベントをQueueに投入する。スタンプと他の非テキストイベントは従来どおり無視する。外部プロバイダー画像は取得しない。
- Queueには画像IDと既存の返信情報だけを載せ、画像バイナリはLINE Content APIの固定宛先から取得する。リダイレクトは禁止し、15秒・8MBを上限としてストリームを読む。JPEG・PNG・WebPのMIMEと先頭バイトを確認する。
- 既存Gemini呼び出しの入力にinlineDataを追加する。同じ予算管理Gatewayを通し、キャッシュ・Gateway本文ログを無効にする。専用プロンプトだけを渡し、会話履歴・プロフィール・長期記憶は渡さない。
- レシート等は家計情報として整理し、その他の文字は文字起こし、文字のない写真は短い感想を返す。判読不能な数字を補わず、画像中の命令を実行しない。家計簿への登録や操作ツールの呼び出しは行わない。
- バイナリと解析結果をアプリ側で永続化しない。DOには画像ID・イベントIDのみ最大24時間保持する。受信した送信取消は処理前と結果送信前の確認で反映する。取消済みIDへの遅延再配信も拒否する。
- 既存Queueの重複処理防止とReply/Push切替を再利用する。

## Consequences

グループに送られた画像は外部AIへ送られる。写真ごとに推論が発生し、遅い回答はPush通数も使う。長い文書・小さな文字の完全なOCRは保証しない。画像の履歴参照・複数画像をまとめた分析は対象外。追加インフラやD1 migrationは不要。

## Enforcement

画像受信・スタンプ除外、グループ制限、画像取得上限、固定ホスト、Queue解析、Geminiへの画像データ受け渡し、取消・重複・期限切れ・非永続化をテストする。pnpm verifyで検証する。

参考：[LINE画像イベント](https://developers.line.biz/en/reference/messaging-api/#wh-image)、[Gemini画像入力](https://ai.google.dev/gemini-api/docs/image-understanding)。
